\begin{minipage}{0.78\textwidth}
\small\itshape
This document supplies the formal ground for the DSTM programming model. It
fixes the objects the model manipulates, states the restrictions a program must
discharge for its execution to be meaningful, gives an axiomatic and an
operational semantics for the runtime, and proves the properties --- write
closure, determinism, deadlock freedom, bounded memory --- that justify
running a distributed simulation without rollback and without global
barriers.
\end{minipage}
