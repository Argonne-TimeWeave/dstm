# current state of experiments

For the SC Workshop PAW-ATM we have two dirs that are up to date: 

(1) simple\_ABMS\_z: our zombies benchmark vs Repast. This benchmark requires Repast and it's zombie model to be build separately. Though, we compare against the exact build that is present within the Repast HPC repo.

(2) airport\_sim/simple\_dstm + airport\_sim/ROSS: our airport benchmark vs ROSS. This benchmark requires ROSS and it's airport model to be built separately. Though, the exact airport model that we compare against is present within airport\_sim/ROSS.

## nonmaintained

zombies, mpi\_air, the other airport sims. The minimal examples should be up to date. 

## mpi\_wrap

mpi\_wrap is an MPI wrap to pick up communication counts.
